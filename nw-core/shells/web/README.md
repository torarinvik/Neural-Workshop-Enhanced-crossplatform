# Browser shell

Runs the WebAssembly build of the core in a web page. `index.html` loads
`../../build/nwcore.wasm`, forwards keyboard and mouse input to it, and
draws the display list it returns onto a canvas.

## Running

From the repository root, after the [setup](../../../README.md#setup) steps:

```bash
nw-core/scripts/build_latest_stage1_wasm.sh
```

```bash
nw-core/scripts/serve_web.sh
```

Then open <http://127.0.0.1:8000/shells/web/index.html>.

The page must be served over HTTP: browsers will not load the WebAssembly
file from a `file://` page. Set `NW_WEB_PORT` to use another port.

## Files

| File | Role |
| --- | --- |
| `index.html` | The page, its controls and the input loop |
| `elisa-wasm-runtime.js` | The small set of host functions the compiled core imports |
| `display-list.js` | Decodes the core's display list and draws it on a 2D canvas |
| `task-registry.js` | Task menu, generated by `scripts/generate_task_registry.py` |
| `result-store.js` | Saves task results in the browser |
| `marble-*.js`, `camera-renderer.js` | WebGL renderers for the 3D tasks |
| `vendor/mujoco/` | MuJoCo physics engine for Marble Maze (Apache-2.0) |
